Multi-Tenant Isolation

To support thousands of medical stores on a single server, each store's database assets are completely isolated from others. Security filters are enforced directly inside the PostgreSQL layer using Row Level Security (RLS) policies. Even if cashier devices communicate directly with the database, they can never inspect or alter data belonging to another store.

Row-Level Security (RLS) Rules

All client transactions run standard parameterized selects. PosgreSQL implicitly appends a security clause: WHERE store_id IN (SELECT get_user_store_ids()). Secure by design at the core engine level!

Offline Sync Engine

MediFlow incorporates an **outbox-pattern offline queue**. If internet connectivity fluctuates in the store, billing proceeds uninterrupted on the local SQLite cache. Modified items, payments, and generated invoices are queued in an offline sync log.

"Server Wins" Conflict Policy

Since cashiers operate within separate stores, global conflict frequencies are close to zero. When sync resumes, conflicts are automatically resolved via a simple Server-Wins timestamp comparison strategy.

Offline-First Visual Data Flow

Every query evaluates locally on the SQLite cache inside the Tauri wrapper. An asynchronous transaction supervisor flushes local changes upward to Supabase once a heartbeat detects a healthy gateway.

Thermal Printing Strategies for Tauri

Medical billing applications must process prints within seconds to maximize checkout speeds. Because MediFlow is structured inside a native Tauri wrapper on Windows, we have three highly reliable mechanisms to interact with receipt printers:

Method A: Standard Web Print (CSS Paginated Layouts)

Implement print layouts inside Next.js using regular HTML/CSS styled specifically with 80mm/58mm boundary limits. Trigger window.print() directly from the frontend interface. The OS spooler handles the native system dialog. Clean, robust, and requires zero extra plugin architecture.

Method B: Tauri Rust Native Printer Spooling

Install and compile tauri-plugin-printer. This enables direct, raw communication with native Windows drivers (e.g. XP-80, Epson TM, TVS). It completely bypasses standard print popups, printing silently and instantly upon invoice finalization.

Standard 80mm Print Layout Spec

Add this specialized media style sheet within your client template directory for clean receipt formatting:

CSS Stylesheet
@media print { @page { size: 80mm auto; /* Fixed 80mm width, dynamic height */ margin: 0; /* Eliminate standard header/footer text */ } body { width: 80mm; font-family: 'JetBrains Mono', monospace; font-size: 11px; color: #000; background: #fff; padding: 4mm; } .receipt-divider { border-top: 1px dashed #000; margin: 2mm 0; } .text-right { text-align: right; } }
